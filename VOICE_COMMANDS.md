# AIILA Voice Commands

This file lists the voice commands currently implemented in AIILA.

## Scan

- `scan unit`
- `scan object`
- `scan device`
- `scan now`

## Page And Layer

- `next page`
- `previous page`
- `next layer`
- `page 1`
- `page 2`
- `layer 1`
- `layer 2`
- `first page`
- `second page`
- `current page`
- `current layer`

## Exploded View

- `show exploded view`
- `show internal`
- `internal view`
- `show me inside`
- `next part`
- `previous part`
- `show next`
- `show previous`
- `hide exploded`
- `close exploded`
- `hide internal`

## Circuit And Draw Mode

- `enable circuit mode`
- `disable circuit mode`
- `toggle circuit mode`
- `enable wire draw mode`
- `disable wire draw mode`
- `toggle wire draw mode`
- `enable draw mode`
- `disable draw mode`
- `toggle draw mode`

## Simulation

- `start simulation`
- `run simulation`
- `stop simulation`
- `disable simulation`
- `toggle simulation`

## Projector

- `project to screen`
- `turn on projector`
- `open projector`
- `start projector`
- `enable projector`
- `turn off projector`
- `close projector`
- `disable projector`
- `stop projector`
- `toggle projector`

## Calibration

- `show calibration grid`
- `open calibration grid`
- `enable calibration grid`
- `turn on calibration`
- `hide calibration grid`
- `close calibration grid`
- `disable calibration grid`
- `turn off calibration`
- `toggle calibration grid`
- `toggle calibration`

## Save And Undo

- `save circuit`
- `save project`
- `save board`
- `undo`
- `undo that`

## Settings

- `open settings`
- `open hardware settings`
- `hardware settings`
- `settings panel`

## Offline AIILA Queries

- `status report`
- `what is scanned`
- `what device is this`
- `what is the model`
- `what mode am i in`
- `which layer`
- `which page`
- `is circuit mode on`
- `is simulation running`
- `is projector active`
- `what tool is selected`
- `is exploded view open`
- `help`
- `what can you do`

## Notes

- Speech-to-text is offline through Vosk.
- Local command actions run without Gemini.
- If a phrase is close to one of the commands above, AIILA may still understand it even if the wording is not exactly the same.
